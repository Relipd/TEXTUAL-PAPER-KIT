# samples · 公开样例与黄金结果

本目录只放**少量公开样例公告**及其抽取结果，用于：

- 安装后离线自检：`python -m audit_kit demo`；
- 回归测试：`tests/` 中逐字段比对「抽取结果 vs 黄金结果」；
- 给使用者直观看到抽取输入（PDF）与输出（JSON）的对应关系。

样例只涉及 3 份公告的公开披露内容，**不代表仓库包含全量数据**；全量公告、SQLite 主库、
`FIN_Audit.csv` 均不随仓库分发。`demo` 不联网、不读数据库、不需要 `FIN_Audit.csv`。

## 1. 目录结构

```
samples/
├─ README.md                 本文件
├─ manifest.json             样例清单（文件、公司、披露年、标题、日期、链接、页数）
├─ pdf/
│  ├─ 000002_1225067818.PDF  万科A：拟续聘 2026 年度会计师事务所
│  ├─ 600519_1219506502.PDF  贵州茅台：变更会计师事务所
│  └─ 601398_ah.PDF          工商银行：聘任会计师事务所（A+H）
└─ expected/
   ├─ 000002_1225067818.json 黄金结果（叙述式）
   ├─ 600519_1219506502.json 黄金结果（版面表格）
   └─ 601398_ah.json         黄金结果（文本兜底）
```

## 2. 三份样例分别展示什么

| 样例 | 公司 / 披露年 | 主题 | 抽取通道 `src` | 展示的能力 |
|---|---|---|---|---|
| `000002_1225067818.PDF` | 万科A / 2026 | 拟续聘 2026 年度会计师事务所 | `prose` | **叙述式**：项目组成员写在「项目合伙人：杨誉民，2007 年成为注册会计师……」这类段落里，姓名与部分时间节点来自叙述正则 |
| `600519_1219506502.PDF` | 贵州茅台 / 2024 | 变更会计师事务所 | `layout` | **版面表格**：项目信息是多列表格，须按坐标重建表格、按表头列对齐取四个时间节点；四节点齐全 |
| `601398_ah.PDF` | 工商银行 / 2024 | 聘任会计师事务所（A+H 公司） | `rawtext` | **文本兜底 + A+H + 无项目合伙人**：版面通道未取到人员，退到文本流取姓名；公开版抽取结果为 A 股人员；该份公告未单列项目合伙人，只有签字注册会计师与复核人 |

三份样例正好覆盖「叙述式 → 版面 → 文本兜底」三级通道，以及「四节点齐全 / 部分节点 /
无项目合伙人」三种典型结果，适合作为回归基线。

| 样例 | 人员 | 说明 |

## 3. 黄金结果格式

`samples/expected/*.json` 的结构：

```json
{
  "_comment": "黄金结果：由基线版本（baseline, v0.1.0）生成，用于回归测试。字段含义见 docs/data-model.md。",
  "sample": {
    "file": "pdf/000002_1225067818.PDF",
    "code": "000002",
    "name": "万科A",
    "disc_year": 2026,
    "title": "关于拟续聘2026年度会计师事务所的公告",
    "date": "2026-04-01",
    "url": "http://static.cninfo.com.cn/finalpage/2026-04-01/1225067818.PDF",
    "pages": 4
  },
  "extract": {
    "roles": {"项目合伙人": ["杨誉民"], "签字注册会计师": ["许湘照"], "质量控制复核人": ["黄天义"]},
    "persons": [
      {
        "role": "项目合伙人",
        "name": "杨誉民",
        "times": {"become_cpa": "2007", "start_listed": "2004",
                  "start_firm": "", "start_company": ""},
        "years": [],
        "source": "prose+ctx"
      }
    ],
    "src": "prose",
    "note": ""
  },
  "meta": {
    "audit_year": "2026",
    "firm_notice": "德勤华永会计师事务所(特殊普通合伙)",
    "prev_firm": "",
    "tenure": "",
    "fee": "1388万元"
  }
}
```

- `sample` 与 `manifest.json` 的条目一致，用于定位 PDF；
- `extract` 是回归比对对象：`demo` 比对 `roles` / `persons` / `src` / `note` 四项；
- `meta` 是公告级元字段（审计年度、事务所公告口径、前任、连续年限、审计收费），
  供人工核对与后续回归使用；
- 黄金结果由基线版本（baseline, v0.1.0）生成，不含人工改写的时间节点；如果抽取逻辑
  有意升级，需要同步重新生成 `samples/expected/`（并更新本文件示例中的 `_comment`），
  并在提交说明中解释差异。

运行 `python -m audit_kit demo`，期望输出：

```text
PASS 000002_1225067818        src=prose    项目合伙人:1、签字注册会计师:1、质量控制复核人:1
PASS 600519_1219506502        src=layout   项目合伙人:1、签字注册会计师:2、质量控制复核人:1
PASS 601398_ah                src=rawtext  签字注册会计师:3、质量控制复核人:1

样例 3 份，通过 3，失败 0
```

单份查看（含公告级元字段时加 `--title` 与 `--disc-year`）：

```bash
python -m audit_kit parse samples/pdf/600519_1219506502.PDF --json
python -m audit_kit parse samples/pdf/600519_1219506502.PDF \
  --title "贵州茅台关于变更会计师事务所的公告" --disc-year 2024
```

## 4. 如何自己添加样例

1. **确认可公开**：只选巨潮资讯网公开披露的公告；确认其内容允许随仓库分发（样例数量
   控制在个位数，避免版权与仓库体积问题）；
2. **命名**：`samples/pdf/<证券代码>_<announcementId>.PDF`；无法取得公告 ID 时用
   `<证券代码>_<场景>.PDF`（如 `601398_ah.PDF`）；
3. **登记清单**：在 `samples/manifest.json` 追加一条（`file`、`code`、`name`、
   `disc_year`、`title`、`date`、`url`、`pages`）；
4. **生成候选结果**：`python -m audit_kit parse samples/pdf/<文件> --json`，得到
   `roles` / `persons` / `src` / `note`；
5. **人工核对**：对照 PDF 原文确认姓名、职位与四个时间节点；按第 3 节格式写入
   `samples/expected/<同名>.json`，保留 `_comment`，补上 `sample` 与 `meta`；
6. **回归**：`python -m audit_kit demo`，确认新增样例 PASS；
7. **更新文档**：在本文件与上级 `README.md` 的样例表中补一行。

> 注意：黄金结果是**回归基线**，不是「绝对正确」；若发现基线版本在该样例上确实抽错，
> 应在修正算法后重新生成黄金结果，并在提交说明中解释「原值 → 新值」的原因。
